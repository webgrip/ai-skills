# The house copy rule (baseline input)

What the estate already banned in its own copy before this skill existed. The merge agents read
this so every point in it ends up as a catalog entry or a cue, and so entries the house already
knew are marked `in_baseline` and stay out of `whats-new.md`.

Ratified 2026-09-02, extended 2026-09-05. Applies to Dutch and English copy alike, and to an
agent's own replies, not only to published text.

## Banned outright

- **Em dashes.** Ordinary sentences with full stops instead. Fact lines use the house separator
  (`//` or `·`). Ratified visual assets that already carry a dash are exempt until their owner
  says otherwise.
- **The not-x-but-y template** in every form: *het is niet x, het is y* · *niet omdat x maar omdat
  y* · *it's not X, it's Y* · *not just X, but Y*. Write the contrast out.
- **Slogan openers of the shape "X, geen Y"** — the same contrast compressed into a first line.
  An opener says what happens; what a thing is *not* belongs in its own block further down, never
  in the heading.
- **The colon reveal**: run-up, colon, payoff.
- **The rule of three** used to sound complete (*faster, cheaper, smarter*). The real count is
  whatever the material has.
- **Throat-clearing and suspense hooks**: *Here's the thing* · *the honest answer* · *what nobody
  tells you*.
- **Aphoristic enders and self-ranking**: *And that matters.* · *That's the part everyone misses*
  · *In short* · *Kortom*.
- **Hollow intensifiers**: *genuinely* · *truly* · *echt* and *gewoon* used as filler.
- **Meta-signposting**: *This matters because* · *Vier kanttekeningen vooraf*.

## Why it is written down

Every item above is a recognisable model tic. Community copy has to read like a person from the
region wrote it, and a bare prohibition does not hold: each rule here names the replacement, which
is what actually changes the output.

The second input to the merge is the de-AI-ify pass in
[`skills/blog-writer/edit-passes.md`](../../../skills/blog-writer/edit-passes.md), which carries
the anti-pattern catalog that predates this skill.
