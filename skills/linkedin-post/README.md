# linkedin-post

The mechanics of getting a LinkedIn post read, separated from the words.

Written after a twente.dev launch post went through eight drafts and three pieces of standard
advice turned out to be wrong for 2026: the first-comment link trick is now penalised, a company
page plus a repost is the weakest way to publish, and the editor silently eats the blank lines
you paste.

Pairs with `humanize`, which handles the prose. This skill handles where it goes, what it asks
for, and how it survives the editor.
